VC Tachie Overlay

OBS のボイスチャット表示を立ち絵に差し替える、URL とカスタム CSS の作成ツールです（Discord StreamKit 用。Discord 公式のツールではありません）。データはこのブラウザの中だけに保存されます。

使い方

  1. 下の「対象のボイスチャンネル」にサーバー ID とボイスチャンネル ID を入れ、「URL をコピー」を押します。
  2. OBS で「ブラウザ」ソースを追加し、URL 欄に貼ります。
  3. 「キャラクター」で Discord ユーザー ID と立ち絵を登録し、「使う」にチェックを入れます。
  4. 「CSS をコピー」を押し、OBS のブラウザソースの「カスタム CSS」の中身を消して貼り付けます。
ID の調べ方と注意

Discord の「ユーザー設定 → 詳細設定 → 開発者モード」をオンにすると、サーバー・チャンネル・ユーザーを右クリックして ID をコピーできます。

Discord のアイコンを設定していない人は、画像の URL に ID が含まれないため立ち絵に差し替えられません。また、Discord 側の更新で StreamKit の構造が変わると CSS が効かなくなることがあります。

対象のボイスチャンネル

Discord の開発者モードをオンにして、サーバーやチャンネルを右クリック →「ID をコピー」。ログインは不要です。

キャラクター

チェックを入れた人だけが CSS に入ります。発言中画像は口を開けた差分など。無ければ待機画像のままです。

プレビュー

OBS に貼る CSS をそのまま見本に当てています。人をクリックすると話している状態を切り替えられます。自由配置のときは立ち絵をドラッグして動かせます（点線が配信画面の範囲）。倍率は見やすさのためだけで、CSS には影響しません。
